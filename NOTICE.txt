1. WHAT THIS IS

The Nexus Bedrock Runtime is a MODIFIED build of the mcpelauncher project, an
open source program that runs Minecraft: Bedrock Edition natively on desktop
operating systems.

    Upstream project : https://github.com/minecraft-linux/mcpelauncher-manifest
    Upstream branch  : ng
    Upstream build   : 0.2.572 (minecraft-linux/macos-builder)

STS Studio modified it for macOS on Apple Silicon. The modifications were made
during 2026, starting from the upstream commit dated 2026-06-25 and continuing
up to the release date of the build named in the RELEASE line above. They cover
OpenGL ES 3.1 window creation, the HTTP worker thread stack size, TLS
certificate authority configuration, headless Google Play credentials, the Xbox
sign in webview lookup path, and an in game overlay.
